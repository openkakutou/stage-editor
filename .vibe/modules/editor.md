# Module: editor
**Role:** The editing screens and the save flow (backlog items 003, 004, 006, 007). `characteristics-editor.ts` edits a loaded stage's name, author, camera bounds, and stage boundaries. `elements-editor.ts` lists, adds, edits, and removes the stage's BG elements, one collapsed row each, and (item 007) lets the user multi-select rows by checkbox — plain click/Space toggles one, Shift-click/Shift-Space selects the whole range since the last individually-selected row — and apply a shared position offset or sprite reassignment to the selection in one action via `bg-element-batch-edit.ts`'s pure functions; selection is tracked by element object reference, never array index, so removing a row never needs reindexing. `model-editor.ts` edits a stage's Ikemen GO 3D model settings — assign/remove a 3D model and `.hdr` lighting file, the model's placement/scale/lighting strength, the 3D camera, `[Scaling]`, and each player's starting depth — and mounts the live 3D preview (`model-preview.ts`, `model-camera.ts`). All three screens mutate the given `StageData` object in place — no patch object, no re-parse round trip. `save-export.ts` reads the document store fresh at click time, serializes it back to `.def` bytes via the WASM bridge, triggers a browser download of the result and marks the document saved (clearing unsaved-changes tracking), or shows the bridge's own error text on a reported failure.
