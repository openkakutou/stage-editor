# Module: editor
**Role:** The editing screens and the save flow (backlog items 003, 004). `characteristics-editor.ts` edits a loaded stage's name, author, camera bounds, and stage boundaries. `elements-editor.ts` lists, adds, edits, and removes the stage's BG elements, one collapsed row each. Both mutate the given `StageData` object in place — no patch object, no re-parse round trip. `save-export.ts` reads the document store fresh at click time, serializes it back to `.def` bytes via the WASM bridge, and triggers a browser download of the result, or shows the bridge's own error text on a reported failure.
**Files:** `src/editor/characteristics-editor.ts`, `src/editor/elements-editor.ts`, `src/editor/save-export.ts`
**Exports:** `renderCharacteristicsEditor(root: HTMLElement, stage: StageData, options?: CharacteristicsEditorOptions): void`, `CharacteristicsEditorOptions`, `renderElementsEditor(root: HTMLElement, stage: StageData | null, spriteGroups: SpriteGroup[] | null, options?: ElementsEditorOptions): void`, `ElementsEditorOptions`, `renderSaveExport(root: HTMLElement, options?: SaveExportOptions): void`, `SaveExportOptions`, `defaultTriggerDownload(bytes: Uint8Array, fileName: string): void`
**Depends on:** `modules/wasm.md` (for `StageData`/`BGElement`/`saveStage`), `modules/sff-wasm.md` (for `SpriteGroup`, sprite reference validation), `modules/document.md` (for the document store `save-export.ts` reads from)
