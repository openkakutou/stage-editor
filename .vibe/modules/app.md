# Module: app
**Role:** Application entry point — builds the app's `web-ui-kit` root frame (toolbar + the stage file input, the New Stage Wizard, characteristics editor, BG element editor, 3D model editor, Save/Export button, and the Keyboard Shortcuts panel as main content) and mounts it into the DOM. A loaded file and a wizard-created stage both funnel through the same `mountDocument` wiring, so the editors appear identically regardless of entry point; a wizard-driven creation additionally moves focus into the characteristics editor. Owns a `Set<BGElement>` for the BG element editor's batch selection (item 007), persisted across re-renders the same way `expandedRows` already is. The toolbar also holds Undo/Redo buttons (item 008): `mountDocument` clears the shared `CommandStack` before storing a new/loaded document, and wires the characteristics/BG element editors' `onChange` to push onto it and refresh the buttons. Owns the single `window` `keydown` listener that dispatches every registered shortcut (item 009), torn down and reattached on every `renderApp` call, and keeps each bound button's shortcut-hint tooltip live via `shortcuts`' `bindShortcutLabel` — including the "Add element" button, whose label is rebound both after `app`'s own rerender and from the elements editor's own `onChange` (that button is recreated by the editor's own internal re-render on every structural change, a path `app`'s own wrapper doesn't see). Mounts a `<wuik-locale-switcher>` in the toolbar and calls `initAppI18n()` from an async `mount()` bootstrap, awaited before the first `renderApp` (item 010); `renderApp` itself stays synchronous. Owns the single top-level `onLocaleChange` subscription that retranslates the switcher's own label, the Undo/Redo buttons' text and shortcut-hint tooltips, and re-invokes the characteristics/model/BG-element editors' and the wizard's own existing render calls on a language switch — each of those preserves whatever state it already threads through other re-render triggers. The stage file input, Save/Export, the 3D live preview's failure banner, and the Keyboard Shortcuts panel section retranslate themselves internally instead.
